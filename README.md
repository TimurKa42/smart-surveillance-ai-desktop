# LookBack (LB)

Проєкт для МАН: знаходить людину/об'єкт на відео за текстовим описом
і збирає звіт зі скріншотами моментів, коли об'єкт було помічено.

Користувач обирає відео, пише словами, кого чи що шукати (наприклад,
«чоловік у червоній куртці» або «білий автомобіль біля воріт»), і
отримує список знайдених моментів з точним часом, коротким описом та
скріншотом у повній якості.

## Можливості

- **Пошук за текстовим описом** (до 200 слів), без попереднього
  навчання моделі під конкретний об'єкт.
- **Два режими аналізу:** «Швидкий» і «Детально» (чотири рівні
  деталізації). Див. розділ [Режими аналізу](#режими-аналізу).
- **Відео до 70 хвилин.** Довші файли відхиляються ще до початку
  аналізу, щоб не витрачати час і ліміти Gemini намарно.
- **Звіт:** зліва список моментів (час + опис), справа скріншот.
  Скріншот можна відкрити на весь екран, збільшувати (кнопки `+` / `-`)
  і рухати мишкою.
- **Експорт у PDF:** один момент або весь звіт одним файлом (по
  сторінці на кожен момент: скріншот, час `ЧЧ:ММ:СС`, опис).
- **Історія аналізів:** кожен запуск зберігається як окрема сесія
  (дата, відео, знайдені кадри) і доступний після перезапуску програми.
- **Перетягування файлу** (drag-and-drop) у головне вікно з перевіркою,
  що це справді відео.
- **Зупинка аналізу** посеред роботи та кнопка «Очистити все».
- **Системне сповіщення** про завершення довгого аналізу.
- **Захист від сну:** поки йде аналіз, комп'ютер не засинає від
  бездіяльності (екран може гаснути).
- **Тема** (Авто / Світла / Темна) і **мова** (українська / англійська)
  перемикаються в самому інтерфейсі й запам'ятовуються.
- **Журнал роботи** у `logs/app.log` (з ротацією) для розбору, що
  відбувалося під час аналізу.

## Як це працює

1. **`main.py`** — вікно програми (CustomTkinter). Користувач обирає
   відео, пише запит, обирає режим і запускає аналіз.
2. **`video_tools.py`** ріже відео на кадри. Це не «кожен N-й кадр»:
   - відео ділиться на рівні відрізки за часом, і з кожного відрізка
     береться рівно один кадр, тож покриваються всі хвилини запису;
   - усередині відрізка вибирається кадр із найбільшим рухом
     відносно «фону» (море, листя, дощ не вважаються рухом), а
     статичні шматки майже не витрачають токени;
   - довжина й поворот відео читаються напряму з MP4, бо OpenCV на
     деяких файлах помиляється (занижений fps, роздута кількість
     кадрів, вертикальне відео «на боці»);
   - програма сама замірює, що швидше для цього файлу: «стрибки» по
     відео, послідовне читання чи апаратне декодування;
   - довгі відео (від 2 хвилин) нарізаються паралельно в кількох
     процесах. Якщо встановлено PyAV, `video_fast.py` бере кадри
     прямо з ключових кадрів, що ще швидше.
3. **`gemini_tools.py`** відправляє кадри пачками по 40 разом із
   запитом у Gemini через REST API. Нарізка й аналіз ідуть
   **паралельно**: перші пачки летять у Gemini, поки відео ще
   нарізається. Gemini повертає строгий JSON: номери кадрів у пачці,
   де щось знайдено, і короткий опис (3-6 слів).
4. Gemini бачить лише номер кадру всередині пачки (0…39). Час знахідки
   програма бере з мітки самого кадру, тож нейромережа не може
   «переплутати» цифри в таймкоді.
5. Для кожного знайденого моменту `video_tools.py` дістає з відеофайлу
   скріншот в оригінальній якості (кадри для Gemini стискаються, а
   скріншоти звіту ні).
6. Результат показується у вікні, зберігається в історію й може бути
   експортований у PDF.

### Стійкість до збоїв

Аналіз довгого відео — це десятки запитів до Gemini, і частина з них
неминуче впирається в ліміти чи збої мережі. Тому:

- **Спільний регулятор темпу.** Після відповіді 429 (перевищено ліміт)
  усі потоки чекають разом, а програма вивчає реальний ліміт ключа
  з відповіді Gemini й далі не перевищує його.
- **Повтори запитів** з наростаючою паузою для мережевих помилок і
  збоїв сервера.
- **Добова квота.** Якщо її вичерпано, програма одразу припиняє марні
  запити й повідомляє про це.
- **Заблокована пачка.** Якщо фільтр безпеки Gemini відхилив пачку, вона
  один раз ділиться навпіл, щоб не втратити решту кадрів.
- **Неповний результат.** Якщо частину кадрів проаналізувати не вдалося,
  програма попереджає про неповний результат, а не мовчки показує
  менше, ніж було знайдено.
- **Збереження знайденого.** Якщо на диску закінчилося місце під час
  збереження скріншотів, уже збережене не пропадає.

## Режими аналізу

Усі режими працюють на одній моделі `gemini-3.5-flash-lite`: проєкт
заточений під дешевизну й доступність на безкоштовному ключі.

| Режим | Кадрів | Глибина «мислення» | Роздільність кадру для Gemini | Запитів |
|---|---|---|---|---|
| Швидкий | 200 | minimal | низька | 5 |
| Детально: Слабкий | 400 | minimal | низька | 10 |
| Детально: Середній (за замовчуванням) | 800 | low | низька | 20 |
| Детально: Високий | 1200 | medium | середня | 30 |
| Детально: Максимальний | 2000 | high | висока | 50 |

Кількість кадрів підібрана кратною розміру пачки (40). Для коротких
відео реальних кадрів менше: нарізка не частіша ніж раз на 0,5 с.

**Обмеження, про які варто знати:** дрібні й далекі об'єкти краще
розпізнаються на високих рівнях (там більша роздільність кадру), а час
знахідки має точність до розміру відрізка (довжина відео ÷ кількість
кадрів). Для 70-хвилинного відео це від ~2 до ~10 секунд залежно від
режиму.

## Встановлення

```bash
pip install -r requirements.txt
```

Примітки:
- `av` (PyAV) потрібен для швидкої нарізки. Без нього програма працює
  по-старому, лише повільніше.
- Системні сповіщення: на macOS використовується
  `pyobjc-framework-UserNotifications`, на Windows/Linux — необов'язкова
  бібліотека `plyer` (`pip install plyer`). Без неї програма працює,
  просто без сповіщень.

## Налаштування ключа

1. Отримай безкоштовний API-ключ у Google AI Studio:
   https://aistudio.google.com/apikey
2. Скопіюй файл `.env.example` у новий файл `.env` і впиши ключ
   замість заглушки. Або просто введи ключ у вікні налаштувань
   програми, він збережеться сам, а працездатність ключа перевіряється
   реальним запитом до Gemini.
3. У меню обери **тип ключа: «Безкоштовний» або «Платний»**. Це
   обов'язкове налаштування, без нього аналіз не стартує. Від нього
   залежить, скільки пачок програма може відправляти одночасно (6 для
   безкоштовного, до 16 для платного), а реальні ліміти запитів
   програма вивчає з відповідей Gemini.

Файл `.env` нікуди публічно не викладай (GitHub тощо), це твій
особистий ключ.

## Запуск

```bash
python main.py
```

## Збірка програми (.exe / .app)

```bash
pyinstaller --noconfirm --clean main.spec
```

PyInstaller не вміє крос-компіляцію: `.exe` збирається на Windows,
`.app` на macOS. У зібраній програмі файли, які вона пише (ключ,
налаштування, історія, скріншоти), лежать у теці користувача:
`%APPDATA%\SmartSurveillanceAI` (Windows) або
`~/Library/Application Support/SmartSurveillanceAI` (macOS). Під час
розробки все лежить поруч зі скриптами.

## Тести

```bash
pytest
```

Тести покривають логіку, яку можна перевірити без інтерфейсу й
мережі: повтори запитів, регулятор темпу, перенумерацію кадрів,
скоринг руху, кеш fps, вибір роздільності кадру.

## Структура проєкту

| Файл | Призначення |
|---|---|
| `main.py` | головне вікно, режими, історія, звіт |
| `video_tools.py` | нарізка відео на кадри, скріншоти |
| `video_fast.py` | швидка нарізка з ключових кадрів (PyAV) |
| `gemini_tools.py` | запити до Gemini, ліміти, повтори |
| `pdf_export.py` | експорт звіту в PDF |
| `history_store.py` | історія аналізів (сесії) |
| `dnd_tools.py` | перевірка перетягнутого файлу |
| `notify_tools.py` | системні сповіщення |
| `keep_awake.py` | захист від сну під час аналізу |
| `config.py`, `settings_store.py` | ключ API, налаштування |
| `localization.py` | рядки інтерфейсу (UA / EN) |
| `app_paths.py`, `app_logging.py` | шляхи й журнал |
| `tests/` | автоматичні тести |

## Приватність і етика

- **Відеофайл ніколи не відправляється в Gemini і нікуди не
  копіюється.** Програма пам'ятає шлях до нього й читає локально. В
  інтернет ідуть лише стиснуті JPEG-кадри (до 1024 пікселів
  по ширині), відібрані з відео.
- Ключ API зберігається локально в `.env`.
- У меню є пункт повного видалення даних програми (ключ, налаштування,
  історія, скріншоти, журнал) із закриттям вікна.
- Умови Google для безкоштовного й платного рівнів Gemini API
  відрізняються тим, як використовуються надіслані дані. Перед
  роботою з реальними записами систем спостереження перевір актуальні
  умови на сайті Google AI.
- Відеозаписи систем спостереження можуть містити персональні дані
  людей, тож використовуй програму лише з відео, на аналіз яких маєш
  право.
